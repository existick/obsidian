# §4. Прямая и плоскость в пространстве

Плоскость $\alpha$: $Ax + By + Cz + D = 0$, нормаль $\vec{N} = {A, B, C}$.

Прямая $l$: $\dfrac{x - x_0}{m} = \dfrac{y - y_0}{n} = \dfrac{z - z_0}{p}$, направляющий вектор $\vec{s} = {m, n, p}$, точка $M_0(x_0, y_0, z_0) \in l$.

## 1) Параллельность прямой и плоскости

$$l \parallel \alpha \iff \vec{N} \perp \vec{s} \iff \vec{N} \cdot \vec{s} = 0 \iff Am + Bn + Cp = 0$$

## 2) Перпендикулярность прямой и плоскости

$$l \perp \alpha \iff \vec{N} \parallel \vec{s} \iff \frac{A}{m} = \frac{B}{n} = \frac{C}{p}$$

## 3) Угол между прямой и плоскостью

Углом между прямой $l$ и плоскостью $\alpha$ называется угол между прямой $l$ и её проекцией на $\alpha$. Обозначим его $\varphi$.

**Случай 1:** $\angle(\vec{N}, \vec{s}) < \dfrac{\pi}{2}$.

$$\varphi = \frac{\pi}{2} - \angle(\vec{N}, \vec{s})$$

$$\sin\varphi = \sin\left(\frac{\pi}{2} - \angle(\vec{N}, \vec{s})\right) = \cos\angle(\vec{N}, \vec{s}) = \frac{Am + Bn + Cp}{\sqrt{A^2 + B^2 + C^2}\cdot\sqrt{m^2 + n^2 + p^2}}$$

**Случай 2:** $\dfrac{\pi}{2} < \angle(\vec{N}, \vec{s}) < \pi$.

Пусть $\psi = \pi - \angle(\vec{N}, \vec{s})$, тогда $\varphi = \dfrac{\pi}{2} - \psi$.

$$\sin\varphi = \sin\left(\frac{\pi}{2} - \psi\right) = \sin\left(\frac{\pi}{2} - \pi + \angle(\vec{N}, \vec{s})\right) = \sin\left(-\frac{\pi}{2} + \angle(\vec{N}, \vec{s})\right) = -\cos\angle(\vec{N}, \vec{s}) = -\frac{Am + Bn + Cp}{\sqrt{A^2 + B^2 + C^2}\cdot\sqrt{m^2 + n^2 + p^2}}$$

Объединяя эти 2 формулы, получим в общем случае:

$$\sin\varphi = \frac{|Am + Bn + Cp|}{\sqrt{A^2 + B^2 + C^2}\cdot\sqrt{m^2 + n^2 + p^2}}$$

## 4) Условие, при котором прямая целиком лежит в плоскости

$\vec{s} \perp \vec{N}$, и точка прямой должна удовлетворять уравнению плоскости:

$$\begin{cases}  
Am + Bn + Cp = 0 \  
Ax_0 + By_0 + Cz_0 + D = 0  
\end{cases}$$

## 5) Точка пересечения прямой и плоскости

Рассмотрим плоскость $\alpha$ и прямую $l$, $\alpha \nparallel l$. Найдём точку пересечения.

$$Ax + By + Cz + D = 0, \qquad \frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{p}$$

Возьмём параметрическое уравнение прямой:

$$\begin{cases}  
x = mt + x_0 \  
y = nt + y_0 \  
z = pt + z_0 \  
Ax + By + Cz + D = 0  
\end{cases}$$

Подставим первые три уравнения в четвёртое:

$$A(mt + x_0) + B(nt + y_0) + C(pt + z_0) + D = 0$$

$$(Am + Bn + Cp),t + Ax_0 + By_0 + Cz_0 + D = 0$$

$$t = -\frac{Ax_0 + By_0 + Cz_0 + D}{Am + Bn + Cp}$$

Подставим $t$ в параметрическое уравнение прямой и получим $M(x, y, z)$.

## Пример

**Текст задания.** Построить уравнение прямой, проходящей через точку $(1, 1, 1)$ и пересекающей прямые

$$l_1: \frac{x}{1} = \frac{y}{2} = \frac{z - 2}{3}, \qquad l_2: \frac{x - 1}{2} = \frac{y - 2}{1} = \frac{z - 3}{4}$$

**Решение.** Используем условие, что 2 прямые лежат в одной плоскости. Пусть $l: \dfrac{x - 1}{m} = \dfrac{y - 1}{n} = \dfrac{z - 1}{p}$ — искомая прямая, $M_0(1, 1, 1)$.

Прямая $l_1$ проходит через $M_1(0, 0, 2)$, $\vec{s}_1 = (1, 2, 3)$. Прямая $l_2$ проходит через $M_2(1, 2, 3)$, $\vec{s}_2 = (2, 1, 4)$.

Условие пересечения $l$ и $l_1$:

$$\begin{vmatrix}  
1 & 1 & -1 \  
1 & 2 & 3 \  
m & n & p  
\end{vmatrix} = 5m - 4n + p = 0$$

Условие пересечения $l$ и $l_2$:

$$\begin{vmatrix}  
0 & -1 & -2 \  
2 & 1 & 4 \  
m & n & p  
\end{vmatrix} = -2m - 4n + 2p = 0 \iff m + 2n - p = 0$$

Система:

$$\begin{cases}  
5m - 4n + p = 0 \  
m + 2n - p = 0  
\end{cases}  
\iff  
\begin{cases}  
5m - 4n = -p \  
m + 2n = p  
\end{cases}$$

Решим по формулам Крамера:

$$\Delta = \begin{vmatrix} 5 & -4 \ 1 & 2 \end{vmatrix} = 14, \quad  
\Delta_m = \begin{vmatrix} -p & -4 \ p & 2 \end{vmatrix} = 2p, \quad  
\Delta_n = \begin{vmatrix} 5 & -p \ 1 & p \end{vmatrix} = 6p$$

$$m = \frac{p}{7}, \qquad n = \frac{3p}{7}$$

Положив $p = 7$, получим $\vec{s} = (1, 3, 7)$.

**Ответ.**

$$\frac{x - 1}{1} = \frac{y - 1}{3} = \frac{z - 1}{7}$$

> [!warning] Заметки по фактчекингу
> 
> - **§3, п. 3:** в параметрических уравнениях в конспекте стояло $y = mt + y_0$, $z = mt + z_0$. Верно: $y = nt + y_0$, $z = pt + z_0$ (из $\frac{y-y_0}{n} = t$, $\frac{z-z_0}{p} = t$).
> - **§3, п. 5:** во втором уравнении плоскости было «$C_2y$» и «$D$». Исправлено на $C_2z$ и $D_2$. У первого уравнения добавлен индекс $D_1$.
> - **§3, п. 6:** в знаменателе $l_2$ было $n_1$, исправлено на $n_2$. Формула угла между прямыми записана с модулем: угол между прямыми лежит в $[0, \frac{\pi}{2}]$. Без модуля формула даёт угол между направляющими векторами. Импликация «$\Rightarrow$» для перпендикулярности заменена на «$\iff$».
> - **§3, п. 7:** «$\vec{s}_1$ и $\vec{s}_2$ компланарны» неверно, два вектора всегда компланарны. В условии определителя участвуют три вектора: $\vec{s}_1$, $\vec{s}_2$ и $\overrightarrow{M_2M_1}$.
> - **§4, п. 3:** в конспекте формула итогового $\sin\varphi$ записана без модуля. В случае 2 выражение $-\cos\angle(\vec N,\vec s)$ положительно, потому что $\cos\angle(\vec N,\vec s)<0$. Объединённая формула должна содержать $|Am+Bn+Cp|$. В случае 1 вместо «$\varphi = \sin(\ldots)$» исправлено на «$\sin\varphi = \sin(\ldots)$».
> - **§4:** нумерация пунктов повторялась («3» дважды, затем «4»). Исправлено на 3, 4, 5.
> - **§4, п. 1:** условие $\vec N\cdot\vec s = 0$ описывает и случай $l \parallel \alpha$, и случай $l \subset \alpha$. Различаются они вторым условием из п. 4.
> - **Пример:** в конспекте допущена ошибка знака при разложении второго определителя. Получено $-2m + 4n + 2p = 0$, верно $-2m - 4n + 2p = 0$. Отсюда неверное уравнение $m - 2n - p = 0$ вместо $m + 2n - p = 0$ и неверный ответ $\frac{x-1}{-1} = \frac{y-1}{-1} = \frac{z-1}{1}$. Проверка показала, что эта прямая не пересекает $l_2$: параметр $t = -2$ даёт точку $(3, 3, -1)$, которая на $l_2$ не лежит. Верный ответ проверен подстановкой: прямая $(1 + t,\ 1 + 3t,\ 1 + 7t)$ пересекает $l_1$ в точке $(2, 4, 8)$ при $t = 1$ и $l_2$ в точке $\left(\frac{7}{5}, \frac{11}{5}, \frac{19}{5}\right)$ при $t = \frac{2}{5}$.
> - **Пример, нечёткое место:** третий элемент первой строки второго определителя в рукописи читается неоднозначно ($-3$ или $-2$). Верное значение $z_0 - z_2 = 1 - 3 = -2$, оно и использовано.

> [!warning] Заметки по добавленному материалу
> 
> - **§3, п. 1–2:** добавлены условия $t \in \mathbb{R}$ и $\vec{s} \neq \vec{0}$, необходимые для корректности уравнений.
> - **§3, п. 5:** добавлено условие непропорциональности коэффициентов нормалей, иначе плоскости параллельны или совпадают и прямой не задают.
> - **§3, п. 6:** добавлены координатные формы условий параллельности и перпендикулярности.
> - **§4, п. 4:** достаточно проверить одну точку прямой вместе с условием $\vec{s} \perp \vec{N}$. Условие «любая точка удовлетворяет уравнению» тогда выполнено автоматически.
> - **§4, п. 5:** знаменатель $Am + Bn + Cp = \vec{N}\cdot\vec{s} \neq 0$, так как $l \nparallel \alpha$. Поэтому $t$ определено однозначно.
> - **Пример:** расписаны точки и направляющие векторы $l_1$, $l_2$ и вывод коэффициентов определителей. В конспекте эти шаги пропущены. Добавлена проверка, что найденное $\vec{s} = (1, 3, 7)$ не коллинеарно $\vec{s}_1$ и $\vec{s}_2$. Это исключает параллельность искомой прямой $l_1$ и $l_2$, при которой определитель тоже обращался бы в нуль.
