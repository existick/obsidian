# §3. Прямая в пространстве

## 1) Векторное уравнение прямой

В системе $Oxyz$ рассмотрим вектор $\vec{s}$ с координатами $m, n, p$: $\vec{s} = {m, n, p}$, $\vec{s} \neq \vec{0}$.

Через точку $M_0(x_0, y_0, z_0)$ проведём прямую $l \parallel \vec{s}$. Пусть $M(x, y, z)$ — произвольная точка прямой. Тогда $\overrightarrow{M_0M} = \vec{r} - \vec{r}_0$, и векторы $\overrightarrow{M_0M}$ и $\vec{s}$ коллинеарны:

$$\vec{r} - \vec{r}_0 = t \cdot \vec{s}, \quad t \in \mathbb{R}$$

— **векторное уравнение прямой**.

## 2) Канонические уравнения прямой

Из условия коллинеарности $\vec{r} - \vec{r}_0 = t\cdot\vec{s}$ координаты пропорциональны:

$$\frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{p}$$

## 3) Параметрические уравнения прямой

$$\frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{p} = t \quad \Rightarrow \quad  
\begin{cases}  
x = mt + x_0 \  
y = nt + y_0 \  
z = pt + z_0  
\end{cases}$$

— **параметрическое уравнение прямой**.

## 4) Прямая через две точки

Через 2 точки $M_1(x_1, y_1, z_1)$ и $M_2(x_2, y_2, z_2)$ можно провести прямую. В качестве направляющего вектора возьмём

$$\vec{s} = \overrightarrow{M_1M_2} = (x_2 - x_1,\ y_2 - y_1,\ z_2 - z_1)$$

$$\frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1} = \frac{z - z_1}{z_2 - z_1}$$

Общий вид: $\dfrac{x - x_0}{m} = \dfrac{y - y_0}{n} = \dfrac{z - z_0}{p}$, $\ \vec{s} = (m, n, p)$.

## 5) Прямая как пересечение двух плоскостей

Возьмём 2 плоскости:

$$\begin{cases}  
A_1x + B_1y + C_1z + D_1 = 0 \  
A_2x + B_2y + C_2z + D_2 = 0  
\end{cases}$$

Прямую в пространстве можно задать как пересечение 2 плоскостей (при условии, что $(A_1, B_1, C_1)$ и $(A_2, B_2, C_2)$ не пропорциональны).

## 6) Взаимное расположение двух прямых

Возьмём 2 прямые:

$$l_1: \frac{x - x_1}{m_1} = \frac{y - y_1}{n_1} = \frac{z - z_1}{p_1}, \qquad  
l_2: \frac{x - x_2}{m_2} = \frac{y - y_2}{n_2} = \frac{z - z_2}{p_2}$$

- $l_1 \parallel l_2 \iff \vec{s}_1 \parallel \vec{s}_2 \iff \dfrac{m_1}{m_2} = \dfrac{n_1}{n_2} = \dfrac{p_1}{p_2}$
- $l_1 \perp l_2 \iff \vec{s}_1 \cdot \vec{s}_2 = 0 \iff m_1m_2 + n_1n_2 + p_1p_2 = 0$
- Угол между прямыми:

$$\cos(l_1 \widehat{\ } l_2) = \frac{|\vec{s}_1 \cdot \vec{s}_2|}{|\vec{s}_1|,|\vec{s}_2|}$$

## 7) Условие принадлежности двух прямых одной плоскости

Две прямые $l_1$ и $l_2$ лежат в одной плоскости $\iff$ векторы $\vec{s}_1$, $\vec{s}_2$ и $\overrightarrow{M_2M_1}$ компланарны:

$$\begin{vmatrix}  
x_1 - x_2 & y_1 - y_2 & z_1 - z_2 \  
m_1 & n_1 & p_1 \  
m_2 & n_2 & p_2  
\end{vmatrix} = 0$$
