

> [!info] Def **Комплексными числами** называются упорядоченные пары $(a,b)$ вещественных чисел, для которых определены следующие действия и отношения:
> 
> **I.** $(a,b) = (c,d) \iff \begin{cases} a=c \ b=d \end{cases}$
> 
> **II.** $(a,b)+(c,d) = (a+c,\ b+d)$
> 
> **III.** $(a,b)\cdot(c,d) = (ac-bd,\ ad+bc)$
> 
> **IV.** $(a,0)$ отождествляется с вещественным числом $a$ и обозначается так: взаимно однозначное соответствие элементов $(a,0) \leftrightarrow a$.

**Обозначение:** $\mathbb{C}$ — множество комплексных чисел.

Для проверки корректности определения нужно проверить согласованность пунктов I–III с правилами действий для вещественных чисел по пункту IV.

- Согласование пунктов I и IV: $(a,0)=(c,0) \iff a=c$
- Согласование пунктов II и IV: $a+c \leftrightarrow (a,0)+(c,0) = (a+c,0) \leftrightarrow a+c$
- Согласование пунктов III и IV: $a\cdot c \leftrightarrow (a,0)(c,0) = (ac - 0\cdot0,\ a\cdot0+0\cdot c) = (ac,0) \leftrightarrow ac$

> [!info] Def Запись пары $(a,b)$, обозначающая некоторое комплексное число $Z$, имеет следующие составляющие: $$a = \operatorname{Re}Z \quad \text{(Real)} — \text{вещественная часть комплексного числа}$$ $$b = \operatorname{Im}Z \quad \text{(Imaginary)} — \text{мнимая часть}$$

## Свойства действий с комплексными числами

**1) Ассоциативность относительно сложения**

$$\big((a,b)+(c,d)\big)+(e,f) = (a,b)+\big((c,d)+(e,f)\big)$$

_Доказательство:_ $$\big((a,b)+(c,d)\big)+(e,f) = (a+c,,b+d)+(e,f) = (a+c+e,,b+d+f) = (a,b)+(c+e,,d+f) = (a,b)+\big((c,d)+(e,f)\big)$$

**2) Коммутативность относительно сложения**

$$(a,b)+(c,d) = (c,d)+(a,b)$$

_Доказательство:_ $$(a,b)+(c,d) = (a+c,,b+d) = (c+a,,d+b) = (c,d)+(a,b)$$

**3) Существование нулевого элемента**

Нулевой элемент — такой элемент, прибавление которого к любому комплексному числу не изменяет последнего.

Число $(0,0)$ является нулевым элементом: $$(a,b)+(0,0) = (a,b)$$

**4) Существование противоположного элемента**

Для любого комплексного числа существует противоположный элемент.

_Доказательство:_ Противоположный элемент к $x$ определяется равенством: сумма с ним равна нулевому элементу $(0,0)$.

Пусть $(-a,-b)$ — противоположный элемент для $(a,b)$, если: $$(a,b)+(-a,-b) = (0,0)$$

**5) Ассоциативность относительно умножения**

$$\big((a,b)(c,d)\big)(e,f) = (a,b)\big((c,d)(e,f)\big)$$

_Доказательство:_ $$(a,b)\cdot\big((c,d)(e,f)\big) = (a,b)(ce-df,\ cf+de) =$$ $$= \big(a(ce-df)-b(cf+de),\ a(cf+de)+b(ce-df)\big) =$$ $$= (ace-adf-bcf-bde,\ acf+ade+bce-bdf) =$$ $$= \big((ac-bd)e-(ad+bc)f,\ (ac-bd)f+(ad+bc)e\big) = (ac-bd,\ ad+bc)(e,f) = \big((a,b)(c,d)\big)(e,f)$$

**6) Коммутативность относительно умножения**

$$(a,b)(c,d) = (c,d)(a,b)$$

_Доказательство:_ $$(a,b)(c,d) = (ac-bd,\ ad+bc) = (ca-bd,\ cb+da) = (c,d)(a,b)$$

**7) Дистрибутивность умножения относительно сложения**

$$\big((a,b)+(c,d)\big)\cdot(e,f) = (a,b)(e,f)+(c,d)(e,f)$$

_Доказательство:_ $$\big((a,b)+(c,d)\big)(e,f) = (a+c,,b+d)(e,f) =$$ $$= \big((a+c)e-(b+d)f,\ (a+c)f+(b+d)e\big) =$$ $$= (ae+ce-bf-df,\ af+cf+be+de) =$$ $$= (ae-bf,\ af+be)+(ce-df,\ cf+de) = (a,b)(e,f)+(c,d)(e,f)$$

**8) Существование единичного элемента**

Единичный элемент — такой элемент, умножение на который любого комплексного числа не изменяет последнего.

Число $(1,0)$ является единичным элементом: $$(a,b)(1,0) = (a\cdot1-b\cdot0,\ a\cdot0+b\cdot1) = (a,b)$$

**9) Существование обратного элемента для любого ненулевого элемента**

_Доказательство:_ Обратный элемент к $(a,b)$ — это такой элемент, умножение $(a,b)$ на который даёт единичный элемент.

Комплексное число $\left(\dfrac{a}{a^2+b^2},\ -\dfrac{b}{a^2+b^2}\right)$ является обратным к $(a,b)$.

_Доказательство:_ $$(a,b)\left(\frac{a}{a^2+b^2},\ -\frac{b}{a^2+b^2}\right) = \left(a\cdot\frac{a}{a^2+b^2} - b\cdot\left(-\frac{b}{a^2+b^2}\right),\ a\cdot\left(-\frac{b}{a^2+b^2}\right)+b\cdot\frac{a}{a^2+b^2}\right) = (1,0)$$

> [!info] Def Множество элементов, для которых определены операции умножения и сложения, обладающие свойствами 1–9, называется **полем**.
> 
> Таким образом, проверив свойства действий с комплексными числами, мы доказали теорему 1.

**Теорема 1.** Множество комплексных чисел образует поле.
